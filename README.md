# Meu guia de consórcios

Página pessoal com orientações, simulador e comparação de propostas.

## Arquivos na raiz do repositório
- index.html: página
- style.css: aparência
- app.js: interações e cálculos
- guia-original.pdf: guia de origem
- planilha-original.xlsx: planilha de origem

## Usar no computador
Extraia o ZIP e abra index.html no navegador, mantendo todos os arquivos na mesma pasta.

## Enviar ao GitHub
Crie um repositório chamado meu-guia-consorcios. Para guardar os arquivos de uso pessoal, escolha Private. Extraia o ZIP e envie todos os arquivos extraídos para a raiz do repositório. Não envie somente o ZIP.

Guardar o código no GitHub não publica automaticamente a página. A proteção de acesso da página hospedada no ChatGPT não está incluída nestes arquivos. Se publicar em outro serviço, configure o acesso nesse serviço.

As entradas do simulador e as marcações do checklist não são salvas após recarregar a página. Não é necessário instalar dependências ou executar build.
